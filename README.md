# CASE — Tasks / первая версия

Интерактивный мобильный макет раздела заданий в стиле предоставленных экранов CASE. Это отдельная страница для обсуждения дизайна и последующей интеграции разработчиком заказчика.

## Открыть

Откройте `index.html` в браузере: сборка и установка пакетов не нужны. Для локального просмотра через HTTP из этой папки:

```text
python -m http.server 4173 --bind 127.0.0.1
```

Затем откройте http://127.0.0.1:4173. Не запускайте сервер из родительской папки: там находятся внутренние заметки и частные материалы проекта.

## Что можно попробовать

- Фильтры All tasks / Social / Daily.
- Подробности задания → Preview task → Check task → Claim reward.
- Задание с уже подтверждённым выполнением и кнопкой Claim reward.
- Completed, прогресс и история демо-баланса по нажатию на число points вверху.
- Справка, Menu и демонстрационные переходы в остальные разделы.
- Внизу страницы — Interactive preview: выбор результата проверки и Reset demo.
- Состояния verifying, verified, rejected, already claimed, expired, retry available, server error, claiming и claimed.

Все задания, суммы и прогресс — примеры, а не сведения о действующих кампаниях CASE. Данные существуют только в памяти страницы и сбрасываются после перезагрузки. Нет регистрации, Telegram-авторизации, подключения кошелька, настоящих rewards, платежей или вывода. Внешних запросов страница не делает.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Структура страницы и демонстрационная оболочка приложения |
| `styles.css` | Стили, адаптивность, цветовые переменные, reduced motion |
| `app.js` | Отображение данных, фильтры, карточки и диалоги |
| `demo-api.js` | Изолированная имитация ответов сервера; не production-логика |
| `assets/` | Созданные для макета векторные иллюстрации и favicon |

Для показа страницы достаточно первых пяти пунктов. Исходники не используют зависимости или внешний CDN. Шрифт — системный: точные брендовые шрифты CASE не предоставлены. Иллюстрации и линейные пиктограммы нарисованы специально для концепта; это не извлечённые игровые assets CASE.

## Что согласовать перед интеграцией

Список и тексты заданий, реальные reward units и суммы, место Tasks в Menu, языки интерфейса, API-контракт, серверную проверку выполнения, шрифты и брендовые материалы. Английский выбран по предоставленным экранам; это рабочее решение, а не утверждённое требование заказчика.

Дизайн не означает готовность production backend. Встраивание, реальные API и аутентификация — следующий согласованный этап.
